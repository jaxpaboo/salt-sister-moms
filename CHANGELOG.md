# Changelog

## 1.0.0 — 2026-11-06

First stable release of Salty Ideas.

- Idea board with seasons, status, difficulty, interest level, and due/post dates
- Materials and checklist tracking (pending/done) on each idea, with a
  completion meter and created date shown on idea cards
- Date sort and status filter (Unposted / Posted / All) on the ideas list
- Inspirations board and sponsors management
- Admin-configurable dropdown options (seasons, statuses) with hardcoded
  fallbacks for a fresh install
- Soft-delete trash view with restore
- URL-synced tabs and mobile-friendly header
- Firebase Realtime Database backend with Identity Toolkit auth; browsing
  works unauthenticated, editing requires sign-in
